# Fixed Emoji font

Twemoji Mozilla v0.7.0 (Twemoji 14 repertoire), unmodified upstream font.

- Source: https://github.com/mozilla/twemoji-colr/releases/tag/v0.7.0
- Download: https://github.com/mozilla/twemoji-colr/releases/download/v0.7.0/Twemoji.Mozilla.ttf
- SHA-256: `6d90152ee0d29e82fe2a87793af5aa4b7ad13e6538360889e141e81ed299ee8e`
- Font construction: Mozilla Foundation, Apache-2.0.
- Emoji artwork: Twitter and Twemoji contributors, CC-BY-4.0.
- License and attribution terms: [LICENSE.md](LICENSE.md).

The COLR/CPAL font is embedded in the client bundle and installed from bytes in
each instrumented realm. It provides a fixed artwork source; operating-system
rasterization and unsupported/newer emoji sequences may still vary.
